# 课程校验记录

校验日期：2026-10-27。范围：7 课讲义、7 个示例、7 套作业题目/答案及构建配置。以下区分真实错误、接口误解与有意的教学简化，不把“编译通过”等同于“知识与模型正确”。

## 1. 确认并修正的问题

| 类别 | 原问题 | 修正 |
|---|---|---|
| BA 代码 | LookAt 参考轴与中心相机视线平行，叉积为零，真值姿态矩阵退化 | 改为不平行参考轴并归一化四元数 |
| BA 代码/模型 | 加噪后的首帧被硬固定，却与原始真值直接比较 | 恢复已知首帧作为统一锚点 |
| BA 可观测性 | 单目 BA 被说成只有 6 维 gauge，固定首帧即可 | 说明 7 维 Sim(3) gauge；额外给定第二帧一个平移分量作为尺度基准 |
| BA 数据 | 按顺序每十条污染一条，可能反复污染同一批路标；扩大相机数还会改变观测覆盖范围 | 先打乱观测再污染，保持相机总覆盖范围不变 |
| BA 数学 | 白化雅可比漏掉 $1/\sigma$；Ceres 半角增量漏掉因子 2 | 区分物理旋转雅可比与 Ceres tangent 雅可比 |
| BA 数学 | Schur 方程与 $g=J^{T} r$ 的定义符号相反，且混淆原始 B 与约化相机图 | 修正符号，区分原始块对角 B 和约化相机矩阵 |
| BA 数值 | 投影没有深度定义域保护 | 非正/近零深度返回无效评估；说明初值与可见性仍需预先保证 |
| 鲁棒统计 | 普通最小二乘被外点拉偏后直接做 MAD，却承诺估出约 0.02 | 改成粗尺度、鲁棒预拟合、重新 MAD；增加尺度正下限与样本检查 |
| 鲁棒统计 | Huber 回归被赋予普适 50% 崩溃点；不同 loss 的 cost 被用于直接判优 | 去除错误保证，区分估计器、污染模型与不同目标函数 |
| 边缘化 | $(1,2,3)$ 被写成旧残差全零点，实际 $r_3=1$ | 基础例子改用 $(0,3,2)$，先验中心为 $(0,3)$；作业保留非最优点 |
| 边缘化数值 | 承诺两种解差小于 `1e-10`，默认 LM 实际相差约 `1e-4` | 对线性满秩例子使用 QR + Dogleg 与明确容差，增加闭式解及等价性检查 |
| FEJ | 被误解释为“同一观测算两次”，冻结先验被当成完整 FEJ | 改为不可观测零空间与线性化一致性；删除 Callback/强阻尼能直接实现 FEJ 的误导 |
| IMU 数学 | 随机游走离散尺度错误；状态转移矩阵混合局部/全局旋转误差 | 给出明确误差约定的一阶示意和 $Q\,\Delta t$ 离散噪声协方差，说明模型边界 |
| IMU 可观测性 | 固定重力的 VIO 被说成任意旋转不变；固定初始速度仅被视为 gauge | 区分典型 VIO 的平移/yaw gauge 与纯 IMU 已知初始条件 |
| IMU 教学结论 | 静止单姿态可独立定加计零偏/重力；陀螺零偏位置误差一律平方增长 | 补充不可分辨条件和重力泄漏产生三次增长的情形 |
| Ceres 接口 | Plus 会修复非单位初值、Jet 赋给 double 会静默变零、QR 必先组装 H | 按官方头文件与算法语义修正 |
| 工程 | 多线程必须 OpenMP、稀疏 Schur 必须 SuiteSparse、空 ordering 当作完成分组 | 纠正后端依赖，提供点/旋转/平移分组片段 |
| 协方差/评估 | 关掉核即可得真实协方差、二维 RMSE 必须等于单分量 σ、轨迹都做 Sim(3) 对齐 | 补充局部协方差、半角尺度、二维噪声/自由度、SE(3)/Sim(3) 协议 |
| 构建/参考代码 | C++14 和最低 Ceres 版本未落实在 CMake；诊断失败仍正常退出 | 声明 C++14、Ceres≥2.1，使用导入目标；关键验证失败返回非零 |

讲义中包含的完整代码摘录与对应 `.cpp` 同步，避免读到过期的参考实现。

## 2. 修正前的可复现现象

本机原始 Release 程序均可启动，但存在下列反例：

- `base04_ba`：重投影 RMSE 约 `0.502 px`，旋转 RMSE 却约 `0.703 rad`；小像素误差不能证明姿态真值和坐标规范正确。
- `hw02_robust`：原始 LS 残差直接 MAD 得到 `sigma_hat` $\approx 0.154$，不满足题目要求的 `[0.015,0.03]`。
- `base06_marginalization` / `hw06_marginalization`：解相差约 `5.25e-5` 和 `1.05e-4`，不满足所声称的 `1e-10`。
- `base03_pose_graph`：ATE 约 `0.422 → 0.168 m`，不是原文承诺的降低一个数量级。
- `base05_imu` / `hw05_imu`：真实运行误差远低于原文举例区间；这些区间不是从当前程序获得。

## 3. 仍然有意保留的简化

- 第 3 课使用 $[2\,\mathrm{vec}(q_e), t_e]$ 分离残差，不是完整 SE(3) Log；边权重为对角近似，合成旋转测量只注入 yaw 噪声，不是完整三轴噪声仿真。
- 第 4 课是合成单目 BA，额外给定尺度基准；没有完整前端、相机畸变模型和鲁棒可见性管理。Huber 不保证所有内点回到纯噪声水平。
- 第 5 课没有实现零偏联合估计、一阶零偏雅可比或预积分协方差传播；作业的“补偿”使用已知真值零偏，不是估计。
- 第 6 课是欧氏线性正定例子，没有实现通用滑窗、流形先验、秩亏消元和完整 FEJ。
- 第 7 课理论协方差对照验证的是同一线性化点下的局部公式，不是 Monte Carlo 一致性证明；综合 VIO 仍是设计题。
- `hw04_ba` 参考代码重点覆盖外点对比与评估；20 相机/500 点的三求解器性能实验仍需按题目扩展，不伪称已经实现或测量。

## 4. 验证方式

核验环境为本机 Ceres 2.1.0 / Eigen 3.3.7 / GCC 9.4 / Release。稀疏后端为 EigenSparse，线程后端为 C++ threads。

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
for target in base01 base02_curve_fitting base03_pose_graph base04_ba \
              base05_imu base06_marginalization base07_engineering \
              hw01_basics hw02_robust hw03_pose_graph hw04_ba \
              hw05_imu hw06_marginalization hw07_engineering; do
    "./build/$target" || exit 1
done
git diff --check
```

结果受平台和随机数分布实现影响。线性等价性使用显式容差；其余课程重点核对误差趋势、有限数值、结果可用性和预期模型行为，不能以单次随机运行证明全局收敛或统计一致性。

## 6. Eigen 数学实现调整（2026-10-29）

第 3～5 课与对应作业的四元数乘法、向量旋转、几何残差和 IMU 预积分改为 Eigen 表达。四元数参数数组仍为 `wxyz`，通过四参数构造函数读取，继续匹配 `QuaternionManifold`；残差类、构造函数、代价函数创建方式、维度、参数块顺序、白化权重和求解器配置沿用原来约定。

六个目标均编译并运行通过。对照保存的原始版本，每个目标用 50 组随机输入比较残差和 ambient 雅可比（共 300 组），并对每个目标的前 10 组输入执行全部参数块的局部中心差分检查。另检查 BA 非正深度，以及 IMU 的零角速度、非零零偏和空积分区间。六个程序输出的误差指标与原始版本在既有打印精度下相符。
