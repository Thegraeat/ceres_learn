## 任务：错误回环下的鲁棒位姿图

以 `base03_pose_graph.cpp` 为起点，保留它的轨迹、噪声和初值逻辑。

### 1. 注入两条错误回环

在生成边之后，找到

- $(i=0, j=5)$
- $(i=5, j=10)$

这两条跨步边，把它们的测量平移在局部 x 方向加 `3.0` 米：

```cpp
if ((e.i == 0 && e.j == 5) || (e.i == 5 && e.j == 10)) {
    e.meas.t[0] += 3.0;
}
```

> 3 米相对于 0.1 米的测量噪声是 30 个 sigma，属于严重的错误关联。

### 2. 比较普通最小二乘与 Huber

用同一组错误边、同一个初值，分别求解：

| 配置 | LossFunction |
|---|---|
| A | `nullptr` |
| B | `HuberLoss(1.0)` |

输出：

- 优化前后的 ATE；
- 两种配置的 ATE；
- `summary.final_cost`。

### 3. 实现旋转误差 ARE

ATE 只衡量平移。再实现旋转误差：

$$
\mathrm{ARE} = \sqrt{\frac{1}{N}\sum_{i=1}^N \theta_i^2},
\qquad
\theta_i = 2\arccos\!\left(|w_i|\right)
$$

其中 $q_i = q_i^{est\,-1} \otimes q_i^{gt}$，$w_i$ 是它的实部。

要求：

- 实现 `RotationError(est, gt)` 和 `AreRmse`；
- 先对四元数做归一化；
- 把 $|w|$ 截断到 $[0,1]$，避免 `acos` 出现 `NaN`；
- 输出单位是弧度，同时换算成度。

### 4. 改变固定节点（思考 + 实验）

把 `SetParameterBlockConstant` 从第 0 个节点改到最后一个节点，重新求解。

回答：

- 最优的 `final_cost` 变了吗？
- ATE / ARE 变了吗？
- 为什么？

## 验收标准

| 检查项 | 标准 |
|---|---|
| 无核 ATE | 明显大于 Huber，通常 > 0.5 m |
| Huber ATE | 在 `0.05 ~ 0.3 m` 量级 |
| `final_cost` | 各自有限且下降；不同 loss 的代价定义不同，不用跨目标的数值大小判优 |
| ARE | 能正常输出，且 Huber 不大于无核 |
| 代码 | 能编译、能运行，两条错误边确实被注入 |

> 无核的 ATE 可能大到 1~3 米。这不是 bug，而是 3 米错误约束把整张图拉歪了。

## 提示

1. 错误边要在**拷贝出来的边集合**上改，不要破坏原始 `edges`，否则航迹推算初值也会被污染。
2. `SPARSE_NORMAL_CHOLESKY` 继续用，20 个节点规模很小，换成 `DENSE_QR` 也能跑。
3. 旋转误差里四元数乘法顺序：
   ```cpp
   QuatConj(est.q, qe_inv);
   QuatMul(qe_inv, gt.q, qe);   // q_est^{-1} * q_gt
   ```
4. `HuberLoss(1.0)` 的阈值作用在白化后的残差上。本作业的 `sigma_rot = 0.02`、`sigma_trans = 0.1`，所以 3 米的错误在平移残差里是 30，在旋转残差里是 0。
