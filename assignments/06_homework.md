## 任务：一般线性化点下的边缘化

以 `base06_marginalization.cpp` 为起点。

### 1. 换成非最优线性化点

把 $x_{lin}$ 从 `(0,3,2)` 改成：

```cpp
const Eigen::Vector3d x_lin(1.2, 1.8, 3.1);
```

此时旧残差在 $x_{lin}$ 处不再为零：

$$
r_1 = 0.0,\qquad r_2 = -0.1,\qquad r_3 = 1.1
$$

要求：

- 重新计算 $H$ 和 $g$；
- 计算消元后的 $H_{prior}$、$g_{prior}$（代码变量名为 `Hmm`、`gm`）；
- 用下式算先验中心：
  $$
  x_{prior} = x_{lin,m} - H_{prior}^{-1}g_{prior}
  $$
- 输出 `Hmm`、`gm`、`x_prior`。

**不要**直接把 `x_lin.head<2>()` 当先验中心。

### 2. 验证等价性

分别求解：

- 全量问题：`x0,x1,x2` + 旧残差 + 新观测 `x0 = 1.1`；
- 边缘化问题：`x0,x1` + 先验 + 新观测。

要求：

- 输出两个解的 `x0,x1`；
- 输出 `|dx0|, |dx1|`；
- 使用参考代码中的 `DENSE_QR + DOGLEG` 与严格停止条件，验证差小于 `1e-10`；默认 LM 停止条件不保证此数值精度。

### 3. 改变新观测

把新观测改成 `x0 = 1.5`，重复任务 1、2。

要求：

- 先验不变，只有新观测变；
- 两个解仍然一致；
- 解释为什么先验不需要重新计算。

### 4. 思考题

1. 如果 $x_{lin}$ 不是旧信息的最优解，先验中心为什么不是 $x_{lin}$？
2. $H_{prior} = H_{mm} - H_{mr} H_{rr}^{-1} H_{rm}$ 的物理含义是什么？
3. 边缘化后，被丢掉的变量还能“回来”吗？
4. FEJ 解决的是什么问题？不用的后果是什么？

## 验收标准

| 检查项 | 标准 |
|---|---|
| $H_{prior}$ | 与 `base06` 相同（线性问题的 H 不依赖线性化点） |
| $g_{prior}$ | 非零，约为 `(0, -0.6)` |
| $x_{prior}$ | 约为 `(0, 3)` |
| 全量/边缘化 | `x0,x1` 差 < `1e-10` |
| 新观测 1.5 | 仍然一致 |

---

## 提示

1. $g = \sum J_i^\top r_i$，$r_i$ 要在 $x_{lin}$ 处算。
2. $H$ 是常数（线性问题），不需要重新算。
3. 先验的 Cholesky 只依赖 $H_{prior}$，新观测变化时不用重算。
4. 全量问题从 `(0,0,0)` 出发，边缘化问题从 `(0,0)` 出发，避免初值偏差掩盖错误。
