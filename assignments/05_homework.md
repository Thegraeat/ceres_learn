## 任务：零偏对预积分的影响

以 `base05_imu.cpp` 为起点。

### 1. 给 IMU 加常值零偏

在生成测量时加入：

```cpp
const Eigen::Vector3d bg_true(0.01, 0.01, 0.01);   // rad/s
const Eigen::Vector3d ba_true(0.1, 0.1, 0.1);      // m/s^2

samples[k].gyro  = omega_true + bg_true + noise;
samples[k].accel = a_body    + ba_true + noise;
```

要求：

- 真值轨迹仍然用来生成观测；
- 预积分时分别测试两种模式：

| 模式 | 预积分使用的零偏 |
|---|---|
| A | `bg = 0, ba = 0`（未补偿） |
| B | `bg = bg_true, ba = ba_true`（已补偿） |

- 两种模式都从同一个带噪初值出发；
- 输出优化前后的位置/速度/姿态 RMSE。

### 2. 观察残差

在优化前，计算第一段预积分的 9 维残差（用真值状态代入），分别输出模式 A 和 B 的残差范数。

要求：

- 模式 A 的残差应该明显更大；
- 模式 B 的残差应该接近噪声水平；
- 解释为什么零偏 0.01 rad/s 在 0.1 秒内就能造成可见的旋转残差。

### 3. 思考题

1. 为什么通常不在每次优化迭代都重新积分？什么时候仍需要重积分？
2. 如果零偏未知，如何在不重新积分的情况下更新预积分量？
3. 陀螺仪零偏和加速度计零偏，哪个对位置影响更大？为什么？
4. 预积分残差的 9 维噪声，能不能只用一个标量 $\sigma$ 白化？为什么？

## 验收标准

| 检查项 | 标准 |
|---|---|
| 模式 A | 优化后误差仍明显大于模式 B |
| 模式 B | 位置 RMSE 降到 0.05 m 以内 |
| 残差范数 | A 明显大于 B |
| 代码 | 能编译、能运行，两种模式从同一初值出发 |

## 提示

1. 生成测量时加零偏，预积分时减零偏：
   ```cpp
   omega_used = samples[k].gyro - bg;
   accel_used = samples[k].accel - ba;
   ```
2. 模式 B 用的是**真值零偏**，这不是“估计”，只是验证补偿是否正确。
3. 两次优化前，把 `est` 重置成同一个初值。
4. 残差计算可以直接复用 `ImuError`，把 `est` 设成真值，手动调用 `operator()`；或者把预积分量和状态代入公式手算。
